## 설계 방향

- 기존 sync workflow를 사용하고 허용 경로·stable 해석·App 토큰 범위를 유지한다.
- writer는 계속 true로 운영하며 신규 stable에 검증된 Draft PR을 생성한다. 병합·릴리즈는 별도 명시적 지시를 따른다.
- 후보 생성 실패는 실제 로그로 분류하고 필요한 호환성만 이 타스크에서 수정한다. 검증 실패를 성공으로 완화하지 않는다.
- native Rust/Tauri와 WASM 재생성은 Linux/Windows CI에서 실행한다. 현재 macOS에서는 플랫폼 중립 검증만 한다.
- 정상 후보는 별도 automation PR로 유지하고 수용 타스크에 연결한다. 생성된 후보를 작업 브랜치에 통합해 최종 검증 후 devel에 반영한다.
- 사용자 최종 Windows 수용 전에는 설치본 준비와 릴리즈 완료를 구분한다.
