# Task #133 수행계획서

GitHub Issue: [#133](https://github.com/postmelee/alhangeul-tauri/issues/133)
마일스톤: M010

## 목적
Windows 설치 차단을 미해결로 명확히 추적하고 보안 해제 없는 설치 안내를 제공한다.

## 배경
v0.1.3 EXE/MSI 설치 차단 제보가 있으며 릴리스는 Authenticode 미서명을 명시한다. 실제 차단 화면이 없어 SAC/SmartScreen 구분은 미확정이다. 서명과 updater Minisign은 별개다.

## 범위
### 포함
현재 미서명 제한, 차단 시 설치 중단과 안전한 제보 항목, Microsoft 공식 설명 링크를 기존 업데이트 안내에 추가한다. 설치 프로그램 자체나 배포는 바꾸지 않는다.
### 제외
인증서 구매·신원확인·서명·보안설정 변경, 릴리스/Pages 배포, 지원 플랫폼 밖 native 검증.

## 설계 방향
홈 다운로드 패널에서 업데이트 안내의 보안 절로 연결한다. 기존 업데이트 페이지에 Windows 보안 안내를 넣는다. SAC 차단을 SmartScreen 경고와 동일시하거나 MSI 선택으로 해결된다고 안내하지 않는다.
