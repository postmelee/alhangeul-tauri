# Stage 1 — 초기화 글꼴 훅 호환성과 취소

GitHub Issue: [#144](https://github.com/postmelee/alhangeul-tauri/issues/144)
구현계획서: [task_m010_144_impl.md](../plans/task_m010_144_impl.md)

## 단계 목적

현행 초기화 서명을 보존하면서 v0.9.1의 AbortSignal 계약에 주입한다.

## 산출물

Studio 진입 훅에 v0.9.1의 고유한 첫 취소 검사 앵커를 추가했다. 신호는 글꼴 컨트롤러에 그대로 전달하고 await 후 재확인한다. 컨트롤러는 문서 세대와 신호를 함께 검사하며 취소가 현재 준비 작업에 해당할 때만 활성 문서와 해당 글꼴 공급을 정리한다. 이전 문서의 신호 리스너는 다음 준비 시작 때 떼어낸다.

## 본문 변경 정도 / 본문 무손실 여부

기존 두 초기화 계약과 글꼴 프롬프트, 상태 보존 분기, 원본 Studio 본문은 유지했다. 주입 대상이 없거나 중복되면 실패한다.

## 검증 결과

현행 핀 전체 Studio 294/294 및 v0.9.1 정확한 Studio 소스와 현행 WASM 조합의 재현 대상 43/43 검사에서 이 단계의 회귀가 통과했다. 취소 전후, 실제 변환된 함수의 status 보존, 교체 이후 화면 갱신 차단을 검사했다. 이 결과는 새 v0.9.1 WASM 검증이 아니다.

## 잔여 위험 / 다음 단계 영향

v0.9.1 제품 글꼴 어댑터 수명주기는 Stage 2에서 확인한다.
