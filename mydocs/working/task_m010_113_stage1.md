upstream source 본문은 수정하지 않았다. Stable tag와 gitlink·resolved commit을 일치시키고
bot의 source/lock/WASM commit·credit·artifact bytes를 보존했다. fixture 10개 고유 파일의 exact
v0.8.7 size/hash가 기존 기대값과 일치해 정의의 current pin 두 필드만 바꿨다.
관리 문서 marker와 승인된 기존 운영 설명만 갱신했다. historical known issue·실패 결과·

## 잔여 위험

- 새 post-commit publisher를 다른 Stable target의 실제 positive writer run으로 실행하지 않았다.
  격리된 계약 회귀·통합 required·현재 pin no-op이 그 full positive run을 대신하지 않는다.
- daily schedule은 default main workflow를 실행한다. 수정한 YAML의 정기 적용은 후속 승인된 main
  승격 때 이뤄진다. 현재 devel 반영을 daily writer 변경 완료로 주장하지 않는다.
- Windows/Linux 전체 native·6종 새 설치 파일·문서/글꼴/출력/thumbnail GUI·서명·공개·production
  upgrade 수용은 미완료다. Ubuntu desktop preflight와 Windows script required만으로 전체 수용하지 않는다.
- macOS에서 Rust/Tauri/wasm-pack을 실행하지 않았다. 기존 build 경고는 유지되며 runtime 성공을 보장하지 않는다.
- task upstream은 sparse checkout이고 cdb7 Git object alternate를 참조한다. task가 의존하는 동안
  그 cache를 정리하지 않으며 최종 delivery 전에 필요한 source/object 가용성을 다시 확인한다.

## 다음 단계 영향

- 현재 제품 version은 0.1.1, upstream은 v0.8.7이다. Stage 2에서 제품 0.1.2 manifest/lock·
  미게시 release record/notes와 기존 생성 규격을 정합화한다.
- 새 `ui/document-title.ts`는 main 시작과 파일명 변경 때 `rhwp-studio` 제목을 다시 쓴다.
  제품 title·blank/document/file-name-change 계약을 최소 제품 hook/leaf에서 보정하고 회귀로 확인한다.
- `data-i18n="ui.studioHeader.srLabel"`은 HTML transform의 제품 한국어 텍스트를 upstream
  `showsOriginal` 경계가 보존한다. 다시 upstream 이름으로 덮는다고 단정하지 않는다. 다만 영어 시작에서도
  제품 한국어 접근성 label이 남을 수 있으므로 실제 initI18n 계약에 맞춰 제품 locale label을 연결한다.
- 상대 font 소비자 5개·새 renderer/catalog 계약의 기존 architecture 설명을 실제 구현에 맞춘다.
  upstream entry/renderer는 복제하지 않고 이미 선택된 문서 위치만 사용한다.
- upstream Cargo patch가 git fork에서 vendored svg2pdf로 변경됐다. 제품 native PDF는 직접
  registry 0.13의 `to_chunk`를 사용하고 생성 lock도 registry다. 제품 PDF 소유 경계와 실제 영향부터
  검토하며 source 비교만으로 새 vendor patch를 적용했다고 또는 회귀라고 주장하지 않는다.
- version/title/locale/notes focused·Node/Studio/automation 검증 후 Stage 2를 보고한다.
  Windows/Linux 설치·native PDF/thumbnail·새 bytes 수용과 공개 gate는 원래 후속 순서를 유지한다.
