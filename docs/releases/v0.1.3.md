# Alhangeul v0.1.3 릴리즈 후보

2026-11-10 기준으로 v0.1.3은 설치본 검증을 앞둔 후보입니다. 현재 공개 버전은 [v0.1.2](v0.1.2.md)입니다.

## 사용자 안내 초안

### 문서 편집과 저장

이번 후보는 문서 편집 엔진을 rhwp v0.8.7에서 v0.9.0으로 올립니다. 새 엔진은 중첩 표가 다음 쪽에 이어질 때 셀 여백과 줄 배치를 처리하는 방식을 개선했습니다. HWP나 HWPX를 저장하고 다시 열 때 표 앞뒤의 본문과 머리말·꼬리말이 보존되도록 보정했습니다. [rhwp v0.9.0 릴리즈 노트](https://github.com/edwardkim/rhwp/releases/tag/v0.9.0)

rhwp Studio는 PDF에서 가져올 쪽과 배치 방식을 선택할 수 있습니다. 원본 배치를 살리거나 편집하기 쉬운 배치를 선택할 수 있으며, 스캔한 글자를 인식하는 OCR은 지원하지 않습니다. 암호를 입력해 PDF를 열었더라도 가져온 문서에 원본 암호가 자동으로 설정되지는 않습니다. Alhangeul 설치본에서의 가져오기 동작은 다음 검증에 포함됩니다.

### Alhangeul 앱 변경

문서에서 요구하는 글꼴을 PC에서 찾을 때 글꼴 이름과 스타일을 함께 확인합니다. PDF 가져오기 작업도 편집 화면과 같은 버전의 문서 엔진을 사용하도록 연결했습니다. [글꼴·Worker 호환성 PR #123](https://github.com/postmelee/alhangeul-tauri/pull/123)

### 설치 및 업데이트

검증할 형식은 Windows x64의 NSIS·MSI, Linux x64의 AppImage·DEB·RPM과 Linux arm64의 DEB입니다. v0.1.3 설치 파일과 자동 업데이트는 아직 제공하지 않습니다. Windows/Linux 설치 후 문서 열기·저장·인쇄와 파일 관리자 썸네일은 후보 파일로 확인할 예정입니다.
