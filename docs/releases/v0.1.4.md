# Alhangeul v0.1.4 릴리즈 기록

상태는 준비 중이다. 실행과 검증은 [#147](https://github.com/postmelee/alhangeul-tauri/issues/147)에서 추적한다.

이전 공개는 [v0.1.3](v0.1.3.md), source `4e99e883eec6bdf9d6ce59070c769f175052fc3f`다. 새 후보는 upstream rhwp v0.9.1 `981ce66b4183b13c1a3b5907e04a8969c8c42034`를 대상으로 한다. 앱의 호환 보정은 [#145](https://github.com/postmelee/alhangeul-tauri/pull/145), 정확한 pin은 [#146](https://github.com/postmelee/alhangeul-tauri/pull/146)에서 검토한다.

## 준비 및 검증

- #146의 빠른 필수 CI는 [44708765183](https://github.com/postmelee/alhangeul-tauri/actions/runs/44708765183)에서 통과했다. 같은 head의 첫 네이티브 검증 [44746621403](https://github.com/postmelee/alhangeul-tauri/actions/runs/44746621403)은 Linux x64/ARM64, Windows 빌드와 코어, MSI, 표준 사용자 NSIS를 통과했다. 관리자 문맥 NSIS에는 알려진 `0x80040154` 관측 외에 새 정상 종료 시간 초과가 있어 전체 수용은 실패다. [44758438233](https://github.com/postmelee/alhangeul-tauri/actions/runs/44758438233)에서 새 러너로 한 번 재현을 확인한다.
- Studio 웹 글꼴 27개를 고정한 upstream의 파일별 고지와 대조했다. 다른 6개를 해당 태그의 파일로 맞췄으며 고지 원문 16개를 패키지 입력에 넣었다. 설치된 패키지의 파일은 최종 후보에서 확인한다.

최종 source·공개일·설치 파일·서명·웹 배포의 식별자는 실제 검증 및 공개 후 기록한다. Windows 설치 프로그램의 Authenticode 상태와 업데이터 서명은 각각 확인한다.
