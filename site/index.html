Alhangeul

Open HWP/HWPX desktop editor

한글 문서를 데스크톱에서

Alhangeul은 Windows와 Linux에서 HWP/HWPX 문서를 열고 편집하기 위한 Tauri 기반 오픈소스 앱입니다. 문서 engine과 renderer는 rhwp를 사용하고, 파일·창·인쇄 같은 데스크톱 통합은 이 프로젝트가 소유합니다.

Project status

현재 개발 중입니다

독립 제품 전환과 Windows/Linux native 검증 기반을 준비하고 있습니다. 공식 설치 파일은 아직 제공하지 않습니다.

  • HWP/HWPX 열기
  • HWP 저장과 PDF 내보내기
  • 인쇄, drag/drop과 다중 창

공개 배포와 자동 업데이트는 별도 검증과 승인 후 제공할 예정입니다.

Alhangeul은 rhwp를 기반으로 하며 MIT 라이선스로 개발됩니다.
