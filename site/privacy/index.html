개인정보처리방침

Windows와 Linux용 Alhangeul 앱과 공식 웹사이트의 데이터 처리를 안내합니다.

작성 기준: 2026년 11월 13일 · Alhangeul v0.1.3

문서와 기기 안의 데이터

앱은 사용자가 선택한 문서의 내용과 파일 경로를 읽어 기기에서 표시·편집하고, 사용자가 정한 위치에 저장하거나 PDF로 내보냅니다. 문서 표시에 설치된 글꼴 목록과 글꼴 파일을 사용할 수 있습니다. 인쇄를 선택하면 운영체제의 인쇄 시스템과 선택한 프린터가 문서를 처리합니다.

최근 문서 목록은 파일 이름과 경로를 앱 데이터 폴더에 저장하며, 편집기 설정은 WebView의 로컬 저장소에 저장합니다. 자동 복구가 활성화된 경우 파일 이름·형식·저장 시각과 문서 복구 데이터가 기기의 IndexedDB에 남을 수 있습니다. 저장·PDF 처리 중에는 임시 파일이, 파일 탐색기 미리보기에는 운영체제의 썸네일 캐시가 생길 수 있습니다.

최근 문서 목록 지우기는 목록을 지우며 원본 문서를 삭제하지 않습니다. 복구 후보는 복구 안내에서 삭제할 수 있습니다. 앱 제거만으로 모든 문서·복구 데이터·로그·운영체제 캐시가 삭제된다고 보장하지 않습니다. 공유 기기에서는 이 데이터에 대한 접근 권한도 관리해 주세요.

사용자가 네트워크 드라이브, 동기화 폴더 또는 네트워크 프린터를 선택하면 해당 운영체제·저장소·인쇄 서비스가 데이터를 처리할 수 있습니다. 이는 아래의 앱 업데이트 통신과 별개입니다.

시작 시 업데이트 확인과 다운로드

업데이트를 지원하는 Windows x64 NSIS·MSI 및 Linux x64 AppImage 설치본은 앱 시작 시 자동으로 새 버전을 확인합니다. 제품 정보에서 수동으로 확인할 수도 있습니다. GitHub Pages의 업데이트 정보를 HTTPS로 요청하므로, 문서를 열지 않아도 외부 통신이 발생할 수 있습니다.

현재 요청 URL은 고정되어 있으며 문서 내용·파일명·파일 경로를 넣지 않습니다. 업데이트 구성요소의 User-Agent와 요청 헤더가 전송되고, GitHub는 접속 IP 주소와 요청에 관한 정보를 처리할 수 있습니다. 앱 버전과 설치 형식에 맞는 업데이트를 앱에서 판별하며, 다운로드 경로는 선택된 버전과 패키지 형식을 나타냅니다.

업데이트가 발견되어도 자동으로 다운로드·설치하지 않습니다. 사용자가 다운로드 및 설치를 선택하면 GitHub Releases와 그 파일 제공 인프라에서 설치 파일을 받습니다. DEB·RPM 및 Linux arm64 등 앱 내 업데이트 비지원 형식은 다운로드 페이지에서 수동으로 확인·설치합니다.

현재 앱에는 시작 시 업데이트 확인을 끄는 설정이 없습니다. 이 요청을 원하지 않으면 운영체제나 네트워크에서 앱의 외부 연결을 제한할 수 있으나 업데이트 확인·다운로드도 이용할 수 없게 됩니다.

로그와 진단

앱의 로그 구성요소는 기기의 로그 파일과 표준 출력에 기록할 수 있으며, 편집기에도 오류·진단용 콘솔 출력이 있습니다. 출력에는 오류 설명, 파일 경로나 인쇄 문서 제목 등 문서와 관련된 정보가 포함될 수 있습니다. 확인한 v0.1.3 코드에는 이 로그를 자동으로 메인테이너에게 보내는 경로가 없습니다.

Windows 썸네일 진단은 사용자가 동의하고 실행하면 공개 테스트 문서로 검사하며 임시 파일과 운영체제 캐시를 만들 수 있습니다. 진단 요약 복사는 클립보드에 내용을 복사합니다. 실제 제보는 사용자가 별도로 보내야 합니다. 로그·진단 요약·화면을 공유하기 전에 민감한 내용을 확인하고 제거해 주세요.

현재 제품 구성과 조사한 코드에서 별도의 광고·사용량 분석 수집이나 문서 자동 업로드 기능은 확인되지 않았습니다. 이것이 운영체제, WebView, 아래 외부 서비스까지 아무 정보도 처리하지 않는다는 뜻은 아닙니다.

사용자가 보내는 문의와 제보

문의는 선택 사항입니다. alhangeul.feedback@gmail.com으로 이메일을 보내면 발신 주소·이름, 본문, 첨부 파일과 메일 전송 정보가 이메일 서비스와 프로젝트 메인테이너에게 전달됩니다. 메인테이너는 답변, 오류 재현과 수정, 보안 제보 대응을 위해 보내주신 내용을 확인합니다. 이메일 링크는 메일 작성 기능을 열며, 사이트가 문서를 자동으로 첨부하거나 전송하지 않습니다.

GitHub Issue에 제출한 내용과 첨부, 계정 정보는 공개될 수 있습니다. 비밀번호·토큰·개인정보나 기밀 원본 문서는 보내지 말고, 필요한 경우 민감한 내용을 제거한 최소 재현본을 사용해 주세요. 보안 취약점은 공개 Issue 대신 보안 정책의 비공개 제보 경로를 이용해 주세요.

웹사이트와 외부 서비스

공식 사이트는 GitHub Pages에서 제공됩니다. 페이지·이미지·스타일과 다운로드 안내 데이터를 불러올 때 요청이 발생합니다. 다운로드 안내는 브라우저의 운영체제 정보를 기기 안에서 참고해 초기 선택을 표시합니다. GitHub는 로그인 여부와 관계없이 Pages 방문자의 IP 주소를 보안 목적으로 기록·보관한다고 안내합니다.

GitHub Pages·Releases·Issues·비공개 취약점 제보에는 GitHub 개인정보처리방침이 적용됩니다. Pages의 데이터 수집 안내도 확인할 수 있습니다. 접속·계정·쿠키·제출 내용의 처리 범위는 서비스와 사용 방식에 따라 다릅니다.

문의 수신함은 Gmail을 사용하므로 Google 개인정보처리방침을 확인해 주세요. 사용자가 사용하는 발신 메일 서비스에도 해당 사업자의 정책이 적용됩니다. 외부 링크를 열면 브라우저 및 방문한 서비스가 자체 정책에 따라 정보를 처리할 수 있습니다.

보관과 삭제 문의

로컬 데이터는 해당 기기의 앱 저장소, 사용자가 선택한 폴더 또는 운영체제 캐시에 남을 수 있습니다. 이 문서는 모든 데이터가 특정 기간 뒤 자동 삭제된다고 약속하지 않습니다. 문의·제보 자료의 보관이나 삭제를 요청하려면 메인테이너에게 이메일로 연락해 주세요. 민감한 원본을 다시 첨부할 필요는 없습니다.

외부 서비스의 보관 기간과 삭제 절차는 각 서비스 정책에 따릅니다. 공개 이슈나 이미 공유된 자료는 복제·인용·백업 때문에 모든 사본의 삭제를 보장할 수 없습니다. 계정이나 서비스에 관한 요청은 해당 제공자의 개인정보 안내도 이용해 주세요.

이 방침의 범위와 변경

이 방침은 위 작성 기준의 Windows·Linux 앱과 공식 사이트 동작을 설명합니다. 기능이나 외부 서비스가 바뀌면 내용을 갱신합니다. 문의 담당은 Alhangeul 프로젝트 메인테이너이며 연락처는 alhangeul.feedback@gmail.com입니다.
