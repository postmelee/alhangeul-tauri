알한글 v0.1.1 릴리즈 안내

공개일: 2026-10-04 KST

로컬 글꼴을 사용할 때 문서를 여는 속도와 입력·스크롤 반응을 개선했습니다. Windows와 Linux 설치 파일을 받을 수 있습니다.

이 버전 다운로드 최신 버전 다운로드

변경 요약

로컬 글꼴을 사용할 때 문서를 여는 속도와 입력·스크롤 반응을 개선했습니다. Windows와 Linux 설치 파일을 받을 수 있습니다.

포함된 rhwp 변화

v0.1.0과 같은 rhwp v0.8.6을 사용합니다. 이번 릴리즈에는 새로운 upstream 기능 변경이 포함되지 않습니다.

알한글 앱 변화

글꼴 이름과 한글 별칭을 찾는 과정에서 같은 글꼴 목록을 반복 조회하던 비용을 줄였습니다. 글꼴 사용 설정 변경과 다시 감지 결과도 조회에 반영됩니다.

고정된 Windows VM에서 Canvas2D·로컬 글꼴 켜짐 조건의 10쪽 HWPX 문서 재열기 중앙값은 18.255초에서 0.516초로, 같은 조건의 Linux VM에서는 2.504초에서 0.636초로 줄었습니다. 공개 문서와 같은 화면 크기로 5회씩 비교한 결과이며, 사용자의 모든 PC와 문서에서 같은 속도를 보장하지는 않습니다.

알려진 한계

  • Windows 설치 파일은 Authenticode 미서명입니다. 자동 업데이트용 Minisign 검증과 운영체제의 코드 서명은 별개입니다.
  • 일부 Windows NSIS 환경에서 탐색기 썸네일이 정상 표시되지 않는 제한이 남아 있습니다. 강제 MSI 설치의 재부팅 후 동작은 검증하지 않았습니다.
  • 사용자의 Wayland·하이브리드 그래픽 환경, 모든 글꼴·문서·배포판과 물리 프린터 조합을 검증하지 않았습니다. 이번 성능 결과만으로 그래픽 드라이버 문제의 해결을 단정하지 않습니다.

설치와 업데이트

Windows x64와 Linux x64를 지원하며, Linux arm64는 DEB 설치 파일을 제공합니다. Windows에서는 WebView2 Runtime이 필요합니다.

Windows는 NSIS 또는 MSI 설치 파일 중 하나를 선택합니다. Linux AppImage는 실행 권한을 부여하고 파일과 폴더에 쓰기 권한이 있는 위치에 보관합니다. DEB·RPM은 배포판에 맞는 패키지를 설치합니다.

Windows NSIS·MSI와 Linux x64 AppImage는 앱 시작 시 또는 제품 정보에서 새 버전을 확인하는 대상입니다. 다운로드 및 설치는 사용자가 선택하며, 저장하지 않은 문서가 있으면 먼저 저장하도록 안내합니다.

Windows NSIS·MSI와 Linux x64 AppImage에서 v0.1.0 → v0.1.1 앱 내 업데이트를 검증했습니다. 업데이트 후 설정 유지와 HWP/HWPX 문서 재열기를 확인했습니다. DEB·RPM과 Linux arm64는 새 패키지를 받아 수동으로 설치합니다.

  • Windows x64 NSIS
  • Windows x64 MSI
  • Linux x64 AppImage
  • Linux x64 DEB
  • Linux x64 RPM
  • Linux arm64 DEB
