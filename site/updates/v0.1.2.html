변경 요약

rhwp v0.8.7을 반영해 표와 문단의 조판, 문서 열기·저장·편집 개선을 포함합니다. Alhangeul의 창 제목과 접근성 이름을 제품명으로 유지하고 새 글꼴 공급 API와 연결합니다.

포함된 rhwp 변화

문단 안 연속 표의 너비·줄바꿈과 중첩 표·행 병합 표의 페이지 분할을 보정했습니다.

빈 머리말·꼬리말이 있는 HWP 저장본과 반복 표 제목·쪽 경계 설정의 저장을 보정했습니다.

Studio 영어 UI, 웹 하이퍼링크 편집, 덮어쓰기 모드와 찾기 결과 개수 표시를 추가했습니다.

표 뒤 Enter와 중첩 표의 선택·삭제·붙여넣기, 글꼴 공급 및 문서 입력 경계의 처리를 보강했습니다.

알한글 앱 변화

기존 로컬 글꼴 선택·이름별 조회·파일 읽기 캐시를 새 upstream renderer API에서도 공유합니다.

새 upstream 시작·문서 제목 처리에서도 Alhangeul 제품명을 유지합니다. native 문서의 수정 상태 표시는 기존 문서 세션이 관리하고, 접근성 이름은 한국어·영어 초기화에 맞춥니다.

CanvasKit 표시 모드에서 로컬 글꼴 파일을 삭제한 뒤 다시 감지할 때 페이지가 비어 보이던 문제를 보정했습니다.

알려진 한계

  • Windows 설치 파일은 Authenticode 미서명이며 자동 업데이트용 Minisign과는 별개입니다.
  • 일부 Windows NSIS 환경에서 탐색기 썸네일이 정상 표시되지 않는 제한이 남아 있습니다. 강제 MSI 재설치의 3010 재부팅 요구를 관측했으며 재부팅 후 동작은 검증하지 않았습니다.
  • 사용자의 모든 Wayland·GPU·글꼴·문서·배포판·물리 프린터 조합은 검증하지 않았습니다. 이전 버전의 성능 수치를 새 pin의 측정 결과로 승계하지 않습니다.

설치와 업데이트

Windows x64와 Linux x64를 지원하며 Linux arm64는 DEB 형식을 준비합니다. Windows에는 WebView2 Runtime이 필요합니다.

Windows는 NSIS 또는 MSI를 선택합니다. Linux x64는 AppImage·DEB·RPM 중 환경에 맞는 형식을 선택합니다. AppImage는 실행 권한과 파일·폴더 쓰기 권한이 필요합니다. Linux arm64는 DEB를 사용합니다.

Windows NSIS·MSI와 Linux x64 AppImage는 앱 시작 시 또는 제품 정보에서 새 버전을 확인합니다. 다운로드·설치는 사용자가 선택하며 저장하지 않은 문서가 있으면 먼저 저장하도록 안내합니다.

v0.1.2 설치 파일을 공개했습니다. v0.1.1 → v0.1.2 앱 내 업데이트 수용은 아직 실행하지 않았습니다. DEB·RPM·Linux arm64는 배포판에 맞는 새 패키지를 수동으로 설치합니다.

  • Windows x64 NSIS
  • Windows x64 MSI
  • Linux x64 AppImage
  • Linux x64 DEB
  • Linux x64 RPM
  • Linux arm64 DEB
