알한글 v0.1.3 릴리즈 안내

공개일: 2026-11-11 KST

이번 v0.1.3 재배포는 Windows 탐색기 썸네일의 첫 실행 지연과 별도 VC 런타임 의존, NSIS 제거 후 파일이 남는 문제를 보정합니다. 문서 엔진은 rhwp v0.9.0을 유지합니다.

이 버전 다운로드 최신 버전 다운로드

변경 요약

이번 v0.1.3 재배포는 Windows 탐색기 썸네일의 첫 실행 지연과 별도 VC 런타임 의존, NSIS 제거 후 파일이 남는 문제를 보정합니다. 문서 엔진은 rhwp v0.9.0을 유지합니다.

2026년 11월 14일 Windows 탐색기 썸네일 수정을 반영해 같은 v0.1.3 설치 파일을 다시 배포합니다. 최초 공개일은 2026년 11월 11일이며, 같은 버전을 이미 사용 중이면 아래 안내에 따라 새 파일을 수동 설치하세요.

포함된 rhwp 변화

중첩 표가 다음 쪽에 이어질 때 셀 여백과 줄 배치를 처리하는 방식을 개선했습니다.

HWP와 HWPX를 저장하고 다시 열 때 표 앞뒤의 본문과 머리말·꼬리말이 보존되도록 보정했습니다.

PDF 가져오기에서 쪽 범위와 원본 배치 또는 편집하기 쉬운 배치를 선택할 수 있습니다. 스캔한 글자를 인식하는 OCR은 지원하지 않습니다.

알한글 앱 변화

처음 썸네일을 만들 때 Windows 작업 프로세스를 시작하는 시간 때문에 문서 렌더링이 일찍 중단되던 문제를 수정했습니다. 렌더링 시간과 메모리 제한은 유지합니다.

썸네일 구성요소가 별도 VC 재배포 런타임 없이 로드되도록 빌드를 수정했습니다.

탐색기가 썸네일 DLL을 잠시 사용 중이면 NSIS 설치·제거가 제한된 시간 동안 기다리도록 했습니다. 제거하지 못한 경우에는 성공으로 숨기지 않습니다.

기존 v0.1.3의 PDF 가져오기 Worker·글꼴 재감지 및 문서 엔진 개선을 포함합니다.

알려진 한계

  • Windows 설치 파일의 Authenticode 서명과 자동 업데이트용 Minisign 서명은 별개입니다. 이번 썸네일 수정은 Smart App Control 문제 해결을 뜻하지 않습니다.
  • 사용자별 NSIS를 관리자 권한 탐색기에서 사용하는 방식은 지원하지 않습니다. 관리자 환경에서는 MSI를 사용하세요.
  • 기존 강제 MSI 재설치에서 관측한 3010 재부팅 요구의 재부팅 후 상태는 별도 검증 전까지 미확인입니다. 일반 설치·같은 버전 교체의 결과와 구분합니다.

설치와 업데이트

Windows x64와 Linux x64를 지원하며 Linux arm64에는 DEB 형식을 제공합니다. Windows에는 WebView2 Runtime이 필요합니다.

일반 사용자 Windows 탐색기에는 사용자별 NSIS를 사용합니다. 관리자 권한 탐색기 또는 UAC가 비활성화된 환경에는 시스템 설치인 MSI를 사용하세요. Windows에는 WebView2 Runtime이 필요합니다.

Linux x64는 AppImage·DEB·RPM 중 배포판에 맞는 형식을 선택하며 Linux arm64는 DEB를 사용합니다. AppImage에는 실행 권한과 파일·부모 폴더의 쓰기 권한이 필요합니다.

이미 v0.1.3을 사용 중이면 같은 버전의 자동 업데이트 알림은 표시되지 않습니다. 작업 중인 문서를 저장하고 앱을 종료한 뒤, 재배포 안내의 날짜와 SHA-256을 확인해 같은 형식의 새 설치 파일을 수동으로 설치하세요.

NSIS와 MSI 사이의 전환은 이번 같은 버전 교체 검증 범위가 아닙니다. DEB·RPM·Linux arm64도 새 패키지를 수동으로 설치합니다.

최초 공개 v0.1.3의 v0.1.2→v0.1.3 자동 업데이트 검증 기록은 이전 파일에 대한 결과입니다. 이번 재배포 파일의 교체 검증 결과는 별도 기록으로 구분합니다.

  • Windows x64 NSIS
  • Windows x64 MSI
  • Linux x64 AppImage
  • Linux x64 DEB
  • Linux x64 RPM
  • Linux arm64 DEB
