알한글 v0.1.3 릴리즈 안내

공개일: 2026-11-11 KST

rhwp v0.9.0을 반영해 표의 페이지 배치와 문서 저장을 개선했습니다. PDF 가져오기 Worker를 같은 엔진에 연결하고 삭제한 글꼴이 재감지 후에도 남던 문제를 보정했습니다.

이 버전 다운로드 최신 버전 다운로드

변경 요약

rhwp v0.9.0을 반영해 표의 페이지 배치와 문서 저장을 개선했습니다. PDF 가져오기 Worker를 같은 엔진에 연결하고 삭제한 글꼴이 재감지 후에도 남던 문제를 보정했습니다.

포함된 rhwp 변화

중첩 표가 다음 쪽에 이어질 때 셀 여백과 줄 배치를 처리하는 방식을 개선했습니다.

HWP와 HWPX를 저장하고 다시 열 때 표 앞뒤의 본문과 머리말·꼬리말이 보존되도록 보정했습니다.

PDF 가져오기에서 쪽 범위와 원본 배치 또는 편집하기 쉬운 배치를 선택할 수 있습니다. 스캔한 글자를 인식하는 OCR은 지원하지 않습니다.

알한글 앱 변화

문서에서 요구하는 글꼴을 찾을 때 이름과 스타일을 함께 확인하도록 글꼴 검색을 개선했습니다.

PDF 가져오기와 문서 편집이 같은 버전의 문서 엔진을 사용하도록 맞췄습니다.

컴퓨터에서 글꼴을 삭제한 뒤 다시 감지해도 삭제한 글꼴이 남아 있던 문제를 수정했습니다. 글꼴 복구·비활성화와 새 창·재시작 후 동작도 확인했습니다.

알려진 한계

  • Windows 설치 파일은 Authenticode 미서명이며 자동 업데이트용 Minisign 서명과는 별개입니다.
  • 일부 Windows NSIS 환경에서 탐색기 썸네일이 정상 표시되지 않습니다. 썸네일이 필요하면 MSI를 사용할 수 있습니다. 강제 MSI 재설치의 3010 재부팅 요구를 관측했으며 재부팅 후 동작은 검증하지 않았습니다.
  • 외부 글꼴이 차단되거나 필요한 글꼴이 없으면 다른 글꼴로 표시되거나 문서 모양이 달라질 수 있습니다.
  • Microsoft Print to PDF 출력은 시각적 내용을 확인했으나 검색 가능한 텍스트가 없습니다. 앱의 직접 PDF 내보내기는 한글 검색을 확인했습니다.
  • PDF 가져오기의 모든 형식·배치 옵션과 사용자 PC의 모든 Wayland·GPU·글꼴·배포판·물리 프린터 조합은 검증하지 않았습니다. PDF 암호를 입력해 가져와도 새 문서에 원본 암호가 자동 적용되지는 않습니다.

설치와 업데이트

Windows x64와 Linux x64를 지원하며 Linux arm64에는 DEB 형식을 제공합니다. Windows에는 WebView2 Runtime이 필요합니다.

Windows는 NSIS 또는 MSI를 선택합니다. Linux x64는 AppImage·DEB·RPM 중 배포판에 맞는 형식을 선택하며 Linux arm64는 DEB를 사용합니다. AppImage에는 실행 권한과 파일·부모 폴더의 쓰기 권한이 필요합니다.

Windows NSIS·MSI와 Linux x64 AppImage는 앱 시작 시 또는 제품 정보에서 새 버전을 확인합니다. 다운로드·설치는 사용자가 선택하며 저장하지 않은 문서는 먼저 저장하도록 안내합니다.

DEB·RPM·Linux arm64는 새 패키지를 수동으로 설치합니다. v0.1.2 → v0.1.3 실제 앱 내 업데이트 결과는 production 피드 게시 후 확인해 안내에 반영합니다.

  • Windows x64 NSIS
  • Windows x64 MSI
  • Linux x64 AppImage
  • Linux x64 DEB
  • Linux x64 RPM
  • Linux arm64 DEB
