arm64 DEB

수동 설치 준비 중

자동 업데이트 지원 범위

  • WindowsNSIS와 MSI 설치본 모두 stable updater를 지원하도록 준비합니다.
  • Linux x64AppImage만 stable updater 대상으로 준비합니다.
  • 수동 설치DEB·RPM과 Linux arm64는 GitHub Releases에서 새 버전을 직접 확인합니다.
