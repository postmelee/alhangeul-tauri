앱에서 업데이트 확인

Issue #16 완료 후 Windows NSIS·MSI 설치본과 Linux x64 AppImage에서 stable 업데이트를 확인할 수 있습니다. 새 버전이 있으면 안내 화면에서 설치 여부를 직접 선택합니다.

설치 형식

Windows x64 NSIS일반 사용자에게 권장하는 설치 형식입니다.

Windows x64 MSI조직과 관리 환경의 정책 기반 배포에 적합합니다.

Linux x64 AppImage독립 실행과 stable 자동 업데이트를 지원할 형식입니다.

Linux x64 DEB · RPM배포판별 수동 설치 형식이며 자동 업데이트 대상이 아닙니다.

Linux arm64 DEB수동 설치 형식이며 새 버전은 GitHub Releases에서 확인합니다.
