앱에서 업데이트 확인

첫 공개 릴리스 검증이 끝나면 Windows x64 NSIS·MSI와 Linux x64 AppImage 설치본은 앱을 시작하거나 제품 정보에서 새 버전을 확인할 수 있습니다. 업데이트가 있어도 자동으로 설치하지 않으며, 사용자가 다운로드 및 설치를 선택해야 진행합니다. 저장하지 않은 문서가 있으면 설치를 막고 먼저 저장하도록 안내합니다. DEB·RPM과 Linux arm64는 GitHub Releases에서 새 버전을 확인해 수동으로 설치합니다.
