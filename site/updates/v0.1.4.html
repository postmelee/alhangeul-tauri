변경 요약

rhwp 문서 엔진을 v0.9.1로 갱신했습니다. 표·문단 조판, 저장 후 다시 열기, 문서 열기와 로컬 글꼴 처리를 보강했습니다.

포함된 rhwp 변화

중첩 표가 쪽을 넘어갈 때 셀 안 그림과 표 뒤 본문의 배치를 보정했습니다.

HWP/HWPX 저장 후 문단·머리말·꼬리말 배치를 보강하고, HTML 표 붙여넣기와 반복 저장에서 일부 서식을 보존하도록 개선했습니다.

문서를 읽는 중 시작 화면의 빈 문서나 자동 복구가 현재 요청을 덮는 경우를 줄였습니다.

알한글 앱 변화

문서를 빠르게 바꾸거나 열기를 취소할 때 이전 문서의 로컬 글꼴 준비가 현재 화면에 적용되지 않도록 보정했습니다.

PDF 처리가 끝난 뒤 문서별 글꼴 배치 자원을 해제하도록 v0.9.1 호환성을 보강했습니다.

편집기에 포함되는 웹 글꼴의 파일별 저작권과 라이선스 원문을 설치 패키지에 동봉합니다.

알려진 한계

  • Windows 설치 파일은 Authenticode 서명이 없어 Smart App Control이나 SmartScreen이 설치를 제한할 수 있습니다. 업데이터는 Minisign으로 다운로드한 파일을 검증합니다.
  • 일부 문서와 글꼴의 배치 차이가 남을 수 있습니다. 관리자 권한 탐색기 또는 UAC를 비활성화한 환경에는 MSI를 사용하세요.

설치와 업데이트

Windows x64와 Linux x64를 지원하며 Linux arm64에는 DEB를 제공합니다. Windows에는 WebView2 Runtime이 필요합니다.

일반 사용자 탐색기에는 사용자별 NSIS를 사용하세요. 관리자 환경 또는 UAC를 비활성화한 환경에는 시스템 설치인 MSI를 사용하세요.

Linux x64는 AppImage·DEB·RPM 중 배포판에 맞는 형식을 선택하세요. Linux arm64는 DEB를 사용하세요.

NSIS·MSI·AppImage는 문서를 저장한 뒤 앱에서 업데이트를 확인하세요. Windows에서는 현재와 같은 설치 형식으로 업데이트하세요.

DEB와 RPM은 기존 배포판과 아키텍처에 맞는 새 파일을 수동으로 설치하세요. AppImage 자동 업데이트에는 파일과 부모 폴더의 쓰기 권한이 필요합니다.

  • Windows x64 NSIS
  • Windows x64 MSI
  • Linux x64 AppImage
  • Linux x64 DEB
  • Linux x64 RPM
  • Linux arm64 DEB
